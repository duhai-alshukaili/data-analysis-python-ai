## Welcome

Welcome to the workshop. This shared folder holds all the material you will use during the week: slides, lab exercises, code files, and datasets. Please read this page before Day 1 and complete the short preparation checklist below.

The workshop is built around one idea: AI tools can speed up research analysis, but only if you can judge what they produce. Throughout the week you will write Python with the help of AI assistants, and you will also learn to test, question, and correct the code and interpretations those assistants give you.

No advanced programming background is expected. Some familiarity with Python helps, and a self-paced review notebook is provided on Day 1 for anyone who wants extra support.

## Before the Workshop: Preparation Checklist

Please complete these steps before Sunday 29 November.

1. **Bring a laptop** with a charger and an up-to-date web browser (Chrome or Edge recommended).
2. **Check your notebook environment.** The workshop runs entirely in the cloud, so you do not need to install Python. Sign in to [Google Colab](https://colab.research.google.com) with a Google account, create a new notebook, type `print("Hello")` in a cell, and run it. If you will use the university JupyterHub instead, access details will be shared on Day 1.
3. **Prepare an AI assistant account.** Create or confirm a free account with at least one of the following: Claude, ChatGPT, or GitHub Copilot. Any of them is suitable for the labs.
4. **Think about your own data (optional).** On Day 5 you can complete the capstone project with a provided dataset or with data from your own research. If you plan to use your own data, bring a small, de-identified sample in `.csv` or `.xlsx` format. Do not bring files containing names, ID numbers, contact details, or other personal information.
5. **Skim the Day 1 folder** so the environment and layout feel familiar when we begin.

## Week at a Glance

**Day 1: Python Foundations and Critical AI-Assisted Coding**
Rapid review of core syntax, lists, dictionaries, and functions. Writing effective prompts for code generation, a structured debugging routine, and a rubric for judging AI-generated code before you run it.

**Day 2: Data Handling, Cleaning, and Exploratory Analysis**
NumPy arrays, loading and inspecting data with pandas, handling missing values and duplicates, grouping and merging, and visualization with Matplotlib and Seaborn.

**Day 3: Statistical Analysis in Python**
Descriptive statistics and distributions, correlation, t-tests, chi-square, and an introduction to ANOVA using scipy and statsmodels. Checking assumptions in code and testing whether an AI-recommended test actually fits your data.

**Day 4: AI-Assisted Interpretation and Introductory Machine Learning**
Judging AI-written interpretations of statistical output, building a personal cross-checking checklist, and fitting linear and logistic regression models with scikit-learn.

**Day 5: Research Ethics, Responsible AI Use, and Capstone**
Data privacy, bias, and disclosure of AI use in research methods sections. An independent capstone analysis on a dataset of your choice, followed by a short share-out and course closing.

## A Note on Using AI with Research Data

Before pasting any data or output into an AI tool, consider whether it contains personal, confidential, or unpublished information. Many AI services may store or process what you submit. During the workshop, work only with the provided public datasets or with your own de-identified samples. Day 5 covers this topic in more depth.
